## Overview

An undergraduate research project exploring Vietnamese semantic similarity and academic text analysis for higher education.

This repository is an early-stage public project overview. It does not yet contain a released research model, an evaluated dataset, or a working application.

## Research focus

The project aims to explore three application areas:

| Research area | Objective |
| --- | --- |
| Semantic duplication detection | Identify potentially similar content beyond exact word matching. |
| Essay assessment support | Explore semantic comparison as evidence to assist human assessment. |
| Curriculum mapping | Explore similarities and overlaps between course descriptions and learning content. |

Similarity scores are supporting evidence, not automatic conclusions of plagiarism or academic misconduct.
